## Quantitative Fact Matrix

The machine-checkable Paper 0/1 traceability matrix is maintained in `references/original_paper/paper_facts.yaml`. It is a grouped baseline from the Nature article Methods, Supplementary Information, Extended Data captions available in the local text extract, Extended Data Tables 1-2, and SI Tables 1-10; each fact includes primary-source evidence, a full bibliographic record with access-dated URL, released-code mapping under `references/original_paper/Mars_IC-main`, local pipeline mapping, a verdict label, and optional `discrepancy_rows` back to this table.

Use the YAML for threshold/window/event-list/bootstrap/filter-band traceability facts. Keep this Markdown table for human-readable implementation discrepancies and interpretive impact notes. Verdict labels are `VERIFIED`, `REFUTED`, `CONFLICTED`, `NO-EVIDENCE`, and `PARTIALLY-VERIFIED`; in the YAML, `NO-EVIDENCE` on a code mapping means that mapping target was checked and no supporting code evidence was found while the fact still carries its primary-source evidence.
